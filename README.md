# BharatCoin - Cryptocurrency Project

A comprehensive cryptocurrency project with code, documents, and research papers. Learn how digital currencies work by building a cryptocurrency from scratch.

## Features

- Blockchain implementation from scratch
- Proof-of-Work consensus mechanism
- Wallet creation and management
- Transaction processing and validation
- Mining functionality
- Peer-to-peer network simulation

## Tech Stack

- **Language:** Python / JavaScript (depending on implementation)
- **Cryptography:** SHA-256 hashing
- **Networking:** WebSocket / HTTP

## Getting Started

### Prerequisites

- Python 3.8+ or Node.js 14+
- pip or npm

### Installation

```bash
git clone https://github.com/RajgopalPandilwar/BharatCoin-Cryptocurrency-Project.git
cd BharatCoin-Cryptocurrency-Project
pip install -r requirements.txt   # For Python implementation
# OR
npm install                        # For Node.js implementation
```

### Usage

```bash
# Start the blockchain node
python main.py

# OR
node index.js
```

### Running Tests

```bash
python -m pytest tests/
# OR
npm test
```
